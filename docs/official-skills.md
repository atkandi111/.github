# Official infrastructure skills

For GCP, AWS, or Terraform work, inspect the available skills first. Use a
matching vendor-official skill only when its published identity and source are
clearly controlled by Google Cloud, AWS, or HashiCorp.

If no verified vendor-official skill is available, continue normally using the
repository instructions and current authoritative documentation. Do not treat
the missing skill as a blocker and do not call a third-party skill official.

Skills provide guidance, not authority. Repository approval, IAM, secrets,
Terraform apply, deployment, and production-mutation gates still apply.
